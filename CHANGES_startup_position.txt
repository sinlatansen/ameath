========================================================================
变更日志：桌宠启动位置 / 启动暂停（用户可配置）
日期：2026-05-11
========================================================================

== 目标 ==

让桌宠每次启动时自动出现在主桌面右下角（任务栏上方）并处于暂停状态，
同时鼠标穿透默认开启。设置只通过用户自己的 config 启用，其他用户不受影响。

关键约束：位置不能写死坐标，每次启动需动态抓取屏幕大小再计算，
以适配换显示器 / 改分辨率 / 调任务栏位置。


== 改动文件 ==

1) ameath/config.py
2) ameath/pet.py


== 详细改动 ==

------------------------------------------------------------------------
[1] ameath/config.py
------------------------------------------------------------------------

(a) DEFAULT_CONFIG 末尾新增 2 个可选配置项：
        "startup_position": None,
        "start_paused": False,

(b) DEFAULT_CONFIG 之后新增预设集合：
        _STARTUP_POSITION_PRESETS = {
            "random",
            "bottom_right",
            "bottom_left",
            "top_right",
            "top_left",
            "center",
        }

(c) _sanitize_config 函数末尾 (return result 之前) 新增 2 项的清洗逻辑：
        val = config.get("startup_position")
        result["startup_position"] = (
            val if isinstance(val, str) and val in _STARTUP_POSITION_PRESETS else None
        )
        result["start_paused"] = _coerce_bool(
            config.get("start_paused"), DEFAULT_CONFIG["start_paused"]
        )

    非法值（不在预设集合中的字符串、错误类型等）一律回退到 None / False，
    不抛异常，不影响程序启动。


------------------------------------------------------------------------
[2] ameath/pet.py
------------------------------------------------------------------------

(a) class DesktopGif 之前新增 2 个模块级函数：

    compute_startup_position(anchor, work_area, pet_size, margin=20)
        - 纯函数：输入屏幕参数 + 锚点，输出 (x, y) 坐标
        - 不读全局状态、不调系统 API、可单元测试
        - 5 个锚点查表：bottom_right / bottom_left / top_right / top_left / center
        - 非法锚点（含 "random"）返回 None，由调用方决定回退策略

    _get_primary_work_area()
        - 调用 Windows API SystemParametersInfoW(SPI_GETWORKAREA=0x0030)
          抓主屏工作区（自动扣除任务栏区域）
        - 返回 (left, top, right, bottom) 或 None（API 失败时）
        - 每次启动现抓，不缓存

(b) DesktopGif.__init__ 中替换硬编码随机位置：

    旧 (pet.py:230-232):
        # 初始出现在屏幕随机位置（配合多开）
        self.x = random.randint(self.screen_x, self.screen_w - self.w)
        self.y = random.randint(self.screen_y, self.screen_h - self.h)

    新:
        # 计算初始位置：每次启动抓屏后计算（"random"/未配置/非法均回退到原有随机逻辑）
        self.x, self.y = self._resolve_startup_position(config)

(c) DesktopGif 新增方法 _resolve_startup_position(config)：
    - 读取 config["startup_position"]
    - 命中 5 个角落锚点 → 调 _get_primary_work_area() 抓主屏工作区
      → 传给 compute_startup_position() 算坐标
    - 值为 "random" / None / 工作区抓取失败 / 锚点非法
      → 一律回退到原有随机逻辑 (random.randint 在 screen_x ~ screen_w 范围内)
    - 保证：未填配置的用户，行为与改动前完全一致

(d) DesktopGif.__init__ 末尾（self.label.bind("<Button-3>", ...) 之后）追加：

        # 启动暂停（可选配置）
        if config.get("start_paused"):
            self.toggle_pause()

    复用现有 toggle_pause() —— 切到 paused 帧 + 调度 paused_anim；
    is_paused=True 时 move() 早期 return，桌宠停在原地不动。


== 用户操作（这一步用户自己做）==

打开 %APPDATA%\ameath_config.json，加 3 个键（注意 JSON 逗号格式）：

    "click_through": true,
    "startup_position": "bottom_right",
    "start_paused": true

下次启动桌宠会：
  1. 动态抓主屏工作区（不写死）
  2. 算出右下角左上角坐标（典型 1707×960 主屏 ≈ (1487, 692)）
  3. 立即暂停 + 鼠标穿透开启

恢复正常运动：右键快捷菜单 → "继续"


== startup_position 可选值汇总 ==

  null              不填或显式 null，走原随机逻辑（默认行为）
  "random"          显式选择随机（与 null 等价，提供给用户明确表达意图）
  "bottom_right"    主屏工作区右下角，离右/下边各 20px
  "bottom_left"     主屏工作区左下角
  "top_right"       主屏工作区右上角
  "top_left"        主屏工作区左上角
  "center"          主屏工作区正中
  其他任意字符串    一律视为非法，静默回退到随机

[运行时验证（用户自测）]
  1. 不动 config 跑 python main.py
     → 行为应与改动前一致：随机位置 + 不暂停
  2. config 加 3 项后重启
     → 右下角 + 不被任务栏挡 + 暂停状态
  3. 改 Windows 缩放或换主屏分辨率后重启
     → 自动落到新尺寸下的右下角
  4. config 写非法值 "startup_position": "foo"
     → 静默回退到随机，不报错
